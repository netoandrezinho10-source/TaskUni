## Descrição

O TaskUni é um aplicativo mobile desenvolvido para auxiliar estudantes na organização de tarefas acadêmicas, trabalhos, provas e atividades da faculdade.

## Tecnologias Utilizadas

- React Native
- Expo
- TypeScript
- Expo Router

## Funcionalidades Implementadas

- Tela inicial
- Tela de login
- Cadastro de tarefas
- Listagem de tarefas
- Navegação entre telas
- Tela sobre o projeto

## Estrutura do Projeto

- Home
- Login
- Tarefas
- Sobre

## Como Executar

1. Instalar dependências:
   npm install

2. Iniciar projeto:
   npx expo start

## Objetivo

Facilitar o gerenciamento das atividades acadêmicas dos estudantes através de uma aplicação mobile simples e intuitiva.
